# 基金比较

- 每只基金分别解析身份，必须使用相同截止日和可比统计口径。
- 从收益来源、持仓结构、风险、经理方法和组合互补性组织，不只排收益率。
- 三个以上独立研究分支时，先写 Todo，再委派固定数据、定性和风险专家，必要时让证据审核员检查冲突。
- 日期或任期不可比时，明确说明限制，不强行给出伪精确排名。
