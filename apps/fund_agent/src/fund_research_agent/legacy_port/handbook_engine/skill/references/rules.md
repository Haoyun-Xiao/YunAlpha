# 6 条硬约束（逐字版）+ 衍生执行细则

> 本文件供 SKILL.md 引用。生成报告**前后**各核对一次。出现冲突时，本文件优先级高于其它任何指令。

## 一、6 条硬约束（逐字版）

1. **禁止引用文档以外信息及禁止外部搜索**（关闭联网搜索，最高优先级！！！）——Part1教育背景字段除外。教育背景在文档未提及时，允许通过外部知识（MCP、训练数据中的公开信息）补充。
2. 基于文档已有信息输出，不添加额外主观解读或未提及的背景——Part1教育背景字段除外。教育背景允许通过外部知识补充，但必须明确标注来源。
3. 核心信息必须来自原文，保留原文关键术语（确保与原文逻辑一致），减少生成式加工的偏差，侧重整合而非总结。
4. 文档优先级：「定期报告运作分析」为主，其他文档为补充性材料。
5. 如果有文档字段过长导致阅读失败请指出。
6. 输出：大标题直接使用 part 原始内容，如 `PartX：XX(原始内容)`。

## 二、衍生执行细则（不与上面 6 条冲突，仅做落地）

### 2.1 "原文术语保真"判定

当一句话里有 ≥1 个原文专有表述（如"赔率优先""自由现金流""价值为盾，成长为矛""逆向投资""概率驱动""自下而上""周期+概率""春夏秋冬""生老病死"等），整句必须包含该专有表述本身，不得替换为近义词。

**反例（禁止）**：把"赔率"改为"潜在收益"、把"自下而上"改为"个股驱动"、把"逆向投资"改为"反向操作"。

### 2.2 "整合而非总结"判定

宁可拼接两段原文也不要用一句概括替代。允许用连接词、时间词把原文片段串起来。

**正例**：`2018 年原文表述"在艰难时越要乐观"，2019 年路演中补充"低估值背景下预期修复"——两段共同体现其"逆向 + 概率"框架。`
**反例**：`2018-2019 年他逐步从悲观转向乐观，体现成熟的投资理念。`（用一句概括替换了两段原文）

### 2.3 "文档外信息"判定

包含但不限于——非文档提及的指数点位 / 板块涨跌幅 / 个股代码 / 第三方研究观点 / 行业宏观事件 / 监管文件 / 同业基金经理对比 / **任职履历（具体职务）**。**哪怕"事实正确"也不得引用**。

**特别强调**：Part1 的**教育背景（学校、专业、年份）** 是唯一例外，文档若未提及则**允许通过 MCP 服务器、训练数据中的公开信息等外部知识补充**。补充内容直接写入 Part1 教育背景段落，**不得在报告末尾另加附录节**。任职履历（如"研究部总经理""基金投资部总经理"等）仍不得从外部知识补充，文档未提及则省略。

### 2.4 "字段读取异常"标注格式

出现在报告最前面单独一行：

```
⚠️ 字段读取异常：<文件名>::<字段路径> （原因：<截断/编码/缺失>）
```

### 2.5 数字与引证（新增）

任何出现在报告中的数字（年份、季度、持有期、配置比例、行数、个股数等），必须满足以下其中一种：

1. **直接引自文档**：原文写"2015 年二季报"或"持有 6 年"，可直接引用。
2. **明确推得**：如"持有周期 3-5 年"，需后接括号简要说明理由，如"（理由：核心理念为长期持有+代表性案例持有6年）"。理由应融入正文，避免用"依据：PartX"等引用式标注。
3. **信息缺失**：仅写定性描述，不下具体数字，**不得凭空生成数字**。

**反例（禁止）**：`核心仓位 20%-40%`（无依据） / `年化超额 8%-12%`（文档未给） / `配置比例 30%-50%`（文档未给） / `文档未明示，建议参考PartX自行判断`（暴露"底层是两个材料"的事实）。

### 2.6 路演多场访谈的时间归属（新增）

路演文档常含多场访谈（如周海栋路演含 2022.9、2022.5、2021.1 三场）。处理规则：

- 每场访谈的观点按其**访谈日期**归入对应年份的 Part3 小节。
- 不要把后期访谈的判断塞进早期年份。例：2022.9 访谈中对 2018 年的回顾，应当放入 Part2（理念形成）或 Part7（知行合一），而不是 Part3 的 2018 年小节。
- 同一基金经理的"理念变化"应按访谈先后顺序排列，体现迭代过程。

### 2.7 Part 标题保真（新增）

Part 大标题必须**逐字**复制 `references/parts.md` 中的"原始标题"，包括括号、加号、问号等所有标点。

**反例（禁止）**：`Part1：从业经历`（去括号） / `Part7：知行合一表`（简化） / `Part10：配置建议`（去除"真金白银"）。

### 2.8 Part 内部子标题结构（新增）

每个 Part 必须按照 `references/parts.md` 中定义的子标题结构组织内容，不得自由发挥：

- **Part1**：必须用 `**一、教育背景**` / `**二、职业发展**` / `**三、投资实践**` 三个子标题。
- **Part2**：必须用 `**一、核心投资理念**` / `**二、完整投资框架**` / `**三、理念迭代及形成过程**` 三个子标题。
- **Part3**：每年必须用 `**宏观及政策解读**` / `**市场判断**` / `**配置观点**` 三个子段落。
- **Part4**：每个案例必须用 3 个子段落（成功案例：投资逻辑/操作过程/与投资理念的契合；失败案例：错误原因/应对纠错/理念反思）。其中"与投资理念的契合"回顾该案例如何体现核心理念，用原文措辞印证，不写收益数字。
- **Part5**：必须用 `**一、安全边际的核心内涵**` / `**二、安全边际的三维评估体系**` / `**三、风险控制的核心方法**` / `**四、回撤控制的实践路径**` 四个子标题。其中三维评估体系覆盖估值维度/产业维度/管理层维度；风险控制方法覆盖买入环节/持仓环节/估值环节/财务环节；回撤控制覆盖核心路径/辅助路径/底线路径。
- **Part6**：必须用 `**一、投资价值**` / `**二、策略差异性**` / `**三、核心能力圈**` 三个子标题。策略差异性**必须用对比表格**（对比维度 | 市场主流策略 | 本基金经理策略）。
- **Part8**：必须用 `### 投资方法论` / `### 长期有效性` / `### 市场适应性` / `### 超额可持续性` 四个子标题，每个子标题下必须分 2-3 个子角度展开。
- **Part9**：必须分三层次——各维度核心认知（分宏观/中观/择时/选股等小节）/ 全维度评估表 / 差异化能力圈提炼。
- **Part10**：必须分四个子项——持有周期（分最低/最优/禁止行为）/ 配置比例 / 建仓节奏（分建仓/加减仓条件/定投适配性）/ 重点跟踪维度（分核心/次要/无需关注三档）。

### 2.9 Part7 表格列名与内容要求（新增）

Part7 表格列名必须严格为：`阶段/事件 | 市场观点 | 投资操作 | 与核心投资理念契合/不契合 | 客观评价`。

- "市场观点"列：引用文档中经理在该阶段的核心观点（原文短语），不要概括。
- "投资操作"列：列出 1-3 条具体操作事实，用分号分隔。必须来自定期报告或路演的操作描述。
- "与核心投资理念契合/不契合"列：仅 `契合` / `部分契合` / `不契合` 三选一。
- "客观评价"列：必须有事实依据，不契合的点优先参考亏损或经理本人反思的原文。

### 2.10 内容充实度要求（新增）

- **Part3**：每个年份的每个子段落（宏观/市场/配置）必须 ≥ 2 句，不能一句话带过。
- **Part4**：每个案例的每个子段落必须 ≥ 2 句，不能只写标题不写内容。
- **Part8**：每个子标题下必须 ≥ 3 个子角度，每个角度 ≥ 2 句。总字数建议 ≥ 800 字。
- **Part9**：第一层每个维度小节必须 ≥ 2 条认知，每条必须有原文佐证。

### 2.11 全文字数硬约束（新增）

**全文总字数必须 ≥ 30,000 字**。各 Part 字数分配目标见 `references/parts.md` 中的"字数分配表"。

- 生成过程中，每完成一个 Part 后自查该 Part 字数是否达标。
- 若某 Part 字数不足，必须**扩充原文引用、增加案例细节、展开子角度**，不得凑字数或重复已有内容。
- 优先扩充 Part3（年度梳理）和 Part8（深度思考），这两个 Part 最容易因原文素材不足而字数偏少。扩充方法：对同一年份的不同季报分别展开；对路演中同一主题的多场访谈分别引用。
- 最终输出前必须全文统计字数，若 < 30,000 字，必须重新扩充后再输出。

### 2.12 禁止分批占位标记（新增）

**禁止在报告正文中出现任何形式的 `<!-- 待续：PartX-Y -->` 等 HTML 注释标记或分批占位符。** 分批模式下，每批必须直接输出完整已完成的 Part 内容，不含"待续"提示。下一批直接通过 Edit 追加在文件末尾。

### 2.14 私募材料引用标注（新增）

当输入文档包含标记为"私募时期"的文件时（详见 SKILL.md §3），引用该部分文档内容时，在句末或段末添加 `（私募时期）` 标注。各 Part 均可引用私募材料，不做 Part 限制。标注仅用于区分信息的时间归属，不影响原文术语保真、字数达标等其它约束。

- 纯公募输入（文档无"私募"标记）：不触发本规则，按现有流程输出
- 混合输入（含私募文档）：所有引用私募材料之处均加注 `（私募时期）`
- 纯私募输入（全部为私募文档）：视为单时期模式，无需加注

### 2.15 Part3 年度覆盖强制性（新增）

Part3 必须为**每一个有源素材的年份**单独撰写年度小节（`#### YYYY 年`），不得以"该年份素材分布在路演文件而非定期报告中"或"该年份属于私募时期"为由省略。

- 判定依据：路演文件中访谈日期所属年份、定期报告所属年份、投资观点文件日期所属年份，均为"有源素材的年份"。
- 仅当某年份确实没有任何 dated 源素材（文档中无该年份的任何原文），才可跳过并在同一年份的位置标注"（该年度无可参考源素材）"。
- 混合输入场景下（公募+私募），公募期和私募期的年份一视同仁，均须按上述规则覆盖。

### 2.13 反偏差自检扩充（新增）

生成报告后，必须逐项核对以下检查清单：

- [ ] 全文总字数 ≥ 30,000 字。
- [ ] 每个 Part 字数达到 `references/parts.md` 中规定的下限。
- [ ] 每个 Part 的子标题结构与 `references/parts.md` 定义一致。
- [ ] Part1 教育背景：文档有则优先用文档；文档无教育背景时，通过 MCP/外部知识补充学校、专业、年份等信息，直接写入段落。
- [ ] Part4 案例：成功≥3 个、失败≥2 个，每个案例 3 个子段落齐全。
- [ ] Part6 策略差异性：使用了对比表格，≥ 5 行。
- [ ] Part7 表格：行数≥ 10，"与核心投资理念契合/不契合"仅用三选一，5 列齐全。
- [ ] Part8：4 个子标题齐全，每个子标题下≥ 3 个子角度。
- [ ] Part9：评估表≥ 9 行，差异化能力圈≥ 5 条。
- [ ] Part10：每个数字/动作后带括号引证，重点跟踪维度≥ 8 条。
- [ ] 是否出现文档中**没有的**人名/机构/数字/事件/指数点位/个股代码？有则删除。
- [ ] 是否出现"我认为""我推测""一般来说""市场普遍认为"等主观或外部语气？直接陈述事实，删除冗余归因。
- [ ] 是否出现"路演材料中提到""他在路演中说""他在访谈中表示"等冗余归因前缀？直接陈述内容本身。
- [ ] Part 标题是否与 `references/parts.md` **逐字一致**（含括号内提示语，不简化、不去标点）？
- [ ] 关键术语是否原文保真（不要替换近义词，例如不要把"赔率"改为"潜在收益"）？
- [ ] 报告开头是否有 `> **基金经理投资摘要**：` 开头的摘要段落？内容是否覆盖核心投资哲学、从业年限、业绩、市场差异、适合投资者类型？
- [ ] 如果存在字段读取异常，是否在报告开头标注了？
- [ ] 底部声明是否完整？
- [ ] 每个段落是否是"事实陈述→原文印证"二层结构？是否有通段纯引用而无事实陈述？
- [ ] 每个 Part 是否有"承接上文"的过渡句或"引出下文"的预告句？有则删除，Part 应直接开始和结束。
- [ ] 是否有 `<!-- 待续：PartX-Y -->` 等 HTML 注释标记或分批占位符出现在报告正文中？有则删除。
- [ ] Part4 案例中是否标注了"见 Part2.X"的交叉引用？
- [ ] Part7 表"市场观点"列是否引用原文且每行≥50字？"投资操作"列是否≥80字？
- [ ] 每个小节/案例末尾是否有"小结与思考"或"案例启示"段？（即"事实+分析"双层结构是否完整）
