## Part1：基金经理从业经历（教育背景+职业发展+投资实践）

**取材**：路演/访谈中的"个人介绍""从业经历""教育背景"段落；定期报告极少涉及，主要靠补充文档。

**写作要点**：
- 采用三个子标题组织：`**一、教育背景**` / `**二、职业发展**` / `**三、投资实践**`。
- **教育背景**：学校/专业/年份/导师方向，文档有则优先用文档原文；**文档未提及教育背景时，允许通过 MCP 服务器、训练数据中的公开信息等外部知识补充**，补充内容直接写入段落。若文档有，展开为一段 200-300 字的描述。
- **职业发展**：按时间线分阶段撰写，每个阶段用一段 300-500 字描述。建议分 3-4 个阶段：`入行起步期（XXXX-XXXX）`→`框架成型期（XXXX-XXXX）`→`成熟践行期（XXXX至今）`。每个阶段标注：年份区间、任职机构、职务角色、覆盖行业、关键事件。
- **投资实践**：首只产品年份及名称、代表产品列表（名称+代码+管理起始日期）、管理规模变化轨迹、关键业绩节点（如"X 年熊市中实现正收益"）、核心操作特征（换手率/持有周期/行业偏好）。写 2-3 段，每段 300-400 字。
- **结构约束**：采用"引导句 + 段落"格式，**禁止把同一信息先嵌套列一遍再扁平列一遍**。
- 不要把"投资理念"写到这里——理念归 Part2。

**定量目标**：
- 教育背景 ≥ 1 段（有则写学校+专业+年份；文档无教育背景时，通过 MCP/外部知识补充，直接写入段落）。
- 职业时间线 ≥ 3 个阶段，每阶段 ≥ 300 字。
- 投资实践 ≥ 3 段，覆盖产品/规模/业绩/操作特征。
- 本 Part 总字数 ≥ 2,000 字。

## Part2：投资理念及投资框架+理念迭代及形成

**取材**：定期报告中反复出现的高频术语和标语；路演中的"投资框架""选股标准""核心信条"段落。

**写作要点**：
- 采用三个子标题：`**一、核心投资理念**` / `**二、完整投资框架**` / `**三、理念迭代及形成过程**`。
- **核心投资理念**（≥ 1,200 字）：
  - 先写**核心信条/一句话总纲**（用原文），展开为一段 200-300 字。
  - 再展开 5-6 条核心原则，每条一个子段落（200-300 字）：`价值投资内核`（赚企业长期价值增长的钱） / `自下而上选股` / `长期持有与低换手` / `安全边际第一原则` / `高集中度持仓原则`。每条用原文短语支撑，不要概括，不添加冗长的"他认为""他指出"等前缀。
- **完整投资框架**（≥ 1,200 字）：按四个子维度展开，每个子维度 300-400 字：
  - `选股框架`：选股标准（如"长坡、厚雪、慢变"）/ 核心量化指标（ROE等）/ 核心关注维度（竞争格局优先于需求）。
  - `交易与持仓框架`：持仓比例原则（与内部收益率正相关、与估值负相关）/ 交易特征（左侧/被动应对）/ 卖出纪律（三种卖出情况）。
  - `组合构建框架`：自下而上选股 / 不做行业分散或集中 / 仓位由个股堆叠。
  - `研究框架`：研究重心（80%在组合外）/ 研究原则（重事实轻逻辑）/ 研究视角（长期观/周期观/历史观）。
- **理念迭代及形成过程**（≥ 1,100 字）：**按"压力/反思/转折"阶段建立时间锚点**，每个阶段 300-400 字：
  - `启蒙与试错期（XXXX-XXXX）`：入行背景、早期做法、遭遇的教训、认知转向。
  - `框架成型期（XXXX-XXXX）`：关键人物/事件影响、核心原则确立、牛熊周期验证。
  - `成熟深化期（XXXX至今）`：公募管理期间的深化、面对市场热点的坚守、框架闭环。

**定量目标**：
- 核心信条 ≥ 1 句（必须是原文短语）。
- 核心原则 ≥ 5 条，每条 ≥ 200 字。
- 框架子维度 ≥ 4 个，每个 ≥ 300 字。
- 理念迭代阶段 ≥ 3 个，每个 ≥ 300 字。
- 本 Part 总字数 ≥ 3,500 字。

## Part3：各阶段（按年度梳理）的宏观及政策解读、市场判断及配置观点（具体板块）

**取材**：定期报告每个季报/年报的"宏观经济证券市场及行业走势展望"+"基金投资策略和运作分析"两个字段。这是本 Part 的核心金矿。

**写作要点**：
- **按年份分小节**（`#### YYYY 年`）。每年包含三个子段落：`**宏观及政策解读**` / `**市场判断**` / `**配置观点**`，每个子段落 3-5 句、200-300 字。
- 同一年若多季报内容相似，合并为一段但仍保留关键差异；存在显著变化时分季度展开（如"一季度...""二季度..."）。
- **路演含日期访谈的归属**：按访谈日期归入对应年份的小节，**不要把后期访谈塞进早期年份**（详见 `rules.md` § 2.6）。路演中的行业分析（如银行/地产/医药深度分析）可归入对应年份的配置观点。
- 不要做跨年总结，也不要排序"哪一年判断最准"。
- 每个子段落必须保留原文关键术语，不要改写为近义词。引用原文时用直引号或引用块。

**定量目标**：
- 覆盖文档中出现的所有年份（如文档覆盖 2019-2025，则全部展开，≥ 7 年）。混合输入场景下（公募+私募），公募期和私募期的年份一视同仁，均有源素材就必须写对应小节。**路演文件的访谈日期也属于"文档出现的年份"，不能因为素材在路演文件而非定期报告中而跳过。**
- 每年 ≥ 3 个子段落，每段 ≥ 200 字、≥ 3 句。
- 本 Part 总字数 ≥ 5,000 字。

## Part4：投资案例复盘：成功+失败（结合投资理念）

**取材**：路演/访谈里"举例""比如""我曾经""我们买过""错过了"等关键词附近段落；定期报告中"持仓置换""减持/增持""错过""遗憾"也可补充。

**写作要点**：
- 分两个二级标题：`### 成功案例` / `### 失败案例（含错过/反思）`。
- **成功案例**格式（每个案例 ≥ 800 字，3 个子段落）：
  - `**投资逻辑（贴合核心理念）**`（≥ 250 字）：为什么买，关联 Part2 哪条理念，买入前做了什么情景假设，如何评估安全边际。
  - `**操作过程**`（≥ 250 字）：时间窗口、买入时点/价格区间（如有）、持有期间操作（加仓/减仓/不动）、持有周期。
  - `**与投资理念的契合**`（≥ 250 字）：回顾该案例如何体现基金经理的核心理念（安全边际、低估值、深度研究等），用原文措辞印证，避免写收益数字、避免写"投资结果"。收益数字仅在文档明确给出时使用，否则用"较好表现""超出基准"等原文措辞。
- **失败案例**格式（每个案例 ≥ 800 字，3 个子段落）：
  - `**错误原因与理念偏差**`（≥ 250 字）：踩了什么坑，违背了哪条原则，当时的判断哪里出了问题。
  - `**应对与纠错**`（≥ 250 字）：发现后做了什么调整，减仓/持有/排雷的具体动作。
  - `**理念反思与迭代**`（≥ 250 字）：从中学到了什么，框架如何修正，后续如何避免同类错误。
- 文档没明确给收益数字时**不要凑数字**；可写"较好表现""超出基准""跑输基准"等原文措辞。

**定量目标**：
- 成功案例 ≥ 3 个（如文档充分披露），每个 ≥ 800 字（含投资逻辑/操作过程/与投资理念的契合三段）。
- 失败/错过/反思案例 ≥ 2 个（如文档披露反思段落），每个 ≥ 800 字。
- 本 Part 总字数 ≥ 4,000 字。

## Part5：风险控制与安全边际分析（结合投资实践）

**取材**：定期报告中"风险""分散""仓位""估值""安全边际"附近表述；路演中专门谈风控的段落。

**写作要点**：
- 采用四个子标题：`**一、安全边际的核心内涵**` / `**二、安全边际的三维评估体系**` / `**三、风险控制的核心方法**` / `**四、回撤控制的实践路径**`。
- **安全边际核心内涵**（≥ 600 字）：定义安全边际的本质——在中性甚至悲观预期下测算企业未来自由现金流折现，仍显著高于买入价格。明确安全边际并非单纯的低估值，低估值只是表现形式之一，真正的安全边际来自对企业价值的深度理解。每点 200-300 字。
- **安全边际的三维评估体系**（≥ 1,200 字）：按三个维度展开，每维度 400-500 字：
  - `**估值维度：基于盈利与资产的估值安全垫**`：PE 20倍、PB 1-2倍为估值分水岭；坚持悲观预期下测算，拒绝基于乐观预期给高估值；典型实践（2017年蓝筹修复后提示无系统性低估等）。
  - `**产业维度：基于行业地位与需求稳定的产业安全垫**`：行业需求长期稳定不崩塌是关键，企业在行业内竞争优势形成底部支撑；不苛求高增长，优先选择竞争格局清晰的行业。
  - `**管理层维度：基于企业家能力与治理结构的管理安全垫**`：勤勉诚恳、坚韧不拔的管理层是安全边际的深层来源；治理结构完善、股东利益导向是核心前提。
- **风险控制的核心方法**（≥ 900 字）：按四个方法展开，每方法 200-250 字：
  - `**买入环节：深度研究+充分安全边际，从源头控制风险**`：仅对深度研究透彻的标的重仓买入，坚决不买研究不深的标的。
  - `**持仓环节：高集中度+深度覆盖，规避分散投资的伪风控**`：集中持仓实现对标的的深度认知，而非通过分散度控制风险。
  - `**估值环节：动态评估性价比，高估值时坚决减仓**`：持续跟踪持仓标的估值变化，透支未来三年时坚决减仓。
  - `**财务环节：严格的财务筛选，规避企业经营与债务风险**`：依托审计背景，严格筛选债务风险和盈利暴雷。
- **回撤控制的实践路径**（≥ 400 字）：
  - `**核心路径：以选股实现回撤控制，而非择时与仓位调整**`：通过精选高安全边际个股实现回撤控制，始终保持85%-90%高仓位。
  - `**辅助路径：组合行业均衡配置，对冲单一行业系统性风险**`：自下而上选股的自然行业均衡。
  - `**底线路径：及时认错止损，规避判断失误的永久性亏损**`：发现基本面判断失误时坚决卖出。

**定量目标**：
- 四个子标题都要写到。
- 三维评估体系三个维度都要覆盖，每维度 ≥ 400 字。
- 风险控制核心方法四个环节都要覆盖，每环节 ≥ 200 字。
- 回撤控制三个路径都要覆盖，每路径 ≥ 150 字。
- 本 Part 总字数 ≥ 3,500 字。

## Part6：投资价值与核心能力（投资价值+策略差异性+核心能力圈）

**取材**：路演中"我和别人有什么不一样""我的能力圈"；定期报告中长期一致的偏好（如行业偏好、市值偏好）。

**写作要点**：
- 采用三个子标题：`**一、投资价值**` / `**二、策略差异性**` / `**三、核心能力圈**`。
- **投资价值**（≥ 1,000 字）：5-6 条，每条 200-250 字。覆盖：价值投资的核心定义 / 价值评估的核心锚点 / 安全边际的核心内涵 / 价值与价格的关系 / 价值投资的市场适配性。每条用原文措辞。
- **策略差异性**（≥ 800 字）：**必须用对比表格**，列名固定 `对比维度 | 市场主流策略 | 本基金经理策略`。维度覆盖：收益来源 / 持仓与交易逻辑 / 选股审美 / 宏观与行业研判 / 风险认知。至少 5 行。表格后附 200-300 字总结。
- **核心能力圈**（≥ 1,200 字）：分三个子维度，每个 300-400 字：
  - `核心能力边界与擅长领域`：原文明确提及的行业/方向（≥ 5 个），每个行业简述其在该领域的独特认知。
  - `能力圈的拓展原则`：如何拓展（80%精力在组合外）、"可理解与可承受"的交集、不盲目追逐热点。
  - `核心研究与决策能力`：长期历史视角（10年以上复盘）/ 多情景假设定价 / 知行合一与情绪管控。

**定量目标**：
- 投资价值 ≥ 5 条，每条 ≥ 200 字。
- 策略差异性：对比表格 ≥ 5 行 + 总结 ≥ 200 字。
- 核心能力圈 ≥ 3 个子维度，每个 ≥ 300 字。
- 本 Part 总字数 ≥ 3,000 字。

## Part7：知行是否合一？"市场观点-投资操作-理念契合/不契合-客观评价"（表格输出）

**强制表格**。列名固定（顺序与措辞完全照搬）：

```
| 阶段/事件 | 市场观点 | 投资操作 | 与核心投资理念契合/不契合 | 客观评价 |
```

**写作要点**：
- 行数 **10-18 行，下限 10 行**，覆盖文档中可识别的关键时间节点（牛熊转折、风格切换、个人反思年份）。
- "与核心投资理念契合/不契合"取值**仅**：`契合` / `部分契合` / `不契合`，三选一。
- "市场观点"列：引用文档中经理在该阶段的核心观点（原文短语），≥ 50 字。
- "投资操作"列：列出 2-3 条具体操作事实（定期报告中的仓位变化、持仓调整、路演中的操作描述），用分号分隔，≥ 80 字。
- "客观评价"列：必须有事实依据，≥ 50 字。**不契合**的点优先参考亏损或经理本人反思的原文。
- 表格下方附一段 200-300 字的总评，总结知行合一的整体表现、不契合点的共性原因。

**定量目标**：
- 表格行数 ≥ 10。
- 至少 1 行 `不契合` 或 `部分契合`（若文档有反思则必有）。
- 每行 5 列齐全，不能有空。
- 本 Part 总字数（含表格+总评）≥ 2,500 字。

## Part8：深度思考：投资方法论、长期有效性、市场适应性、超额可持续性

**取材**：路演/访谈中谈"长期""穿越周期""适应市场""α 来源"等段落；以及 Part7 表格中得出的契合/不契合规律。

**写作要点**：
- 四个二级标题对齐：`### 投资方法论` / `### 长期有效性` / `### 市场适应性` / `### 超额可持续性`。
- **投资方法论**（≥ 1,200 字）：展开为五个子模块，每个 200-300 字：`核心理念层`（价值定义/市场观/收益观/风险观）/ `选股框架层`（核心锚点/筛选标准/估值定价/行业偏好）/ `交易体系层`（交易原则/仓位管理/换手率）/ `研究体系层`（研究原则/精力分配/研究深度）/ `风险控制体系`（事前/事中/组合分散）。
