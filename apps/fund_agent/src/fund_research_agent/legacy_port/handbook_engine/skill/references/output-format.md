# 输出格式规范

## 一、文件名与覆盖保护

- **默认文件名**：`<基金经理名>_report.md`，写入用户当前工作目录（或用户指定路径）。
- **覆盖保护**：写文件前先检查同名文件是否存在；若存在，自动追加 `_v2 / _v3 / _v4 …` 后缀。
  - 例：`周海栋_report.md` 已存在 → `周海栋_report_v2.md`。
- **绝不静默覆盖**已有文件。

## 二、整体骨架

### 纯公募模式（仅含普通文档）

```markdown
# <基金经理名> 投资手册

> **基金经理投资摘要**：<一段话（250-400字）概括基金经理。覆盖：核心投资哲学（1-2句）、从业年限与框架迭代（1句）、代表业绩（1句）、与市场主流的核心差异（1-2句）、适合的投资者类型（1句）。以"适合XXX的投资者"结尾。>
```

### 公募+私募混合模式（含标记为"私募时期"的文档）

混合模式在文档头部增加时期分组信息，各 Part 引用私募材料时在内容末尾加 `（私募时期）` 标注。

框架示例：

```markdown
# <基金经理名> 投资手册

> 主文档（公募期）：<文件名>
> 主文档（私募期）：<文件名>
> 补充文档（公募期）：<文件名>
> 补充文档（私募期）：<文件名>
> 生成依据：仅基于上述文档原文，未引用任何外部信息。

> **基金经理投资摘要**：<一段话（250-400字）概括基金经理。>

## 七、引用原文的格式

- **短语级（≤15 字）**：直接放入正文，加直引号——例："价值为盾，成长为矛"。避免写"经理强调""经理认为"等冗余归因。
- **句子级（>15 字）**：用 `> ` 引用块单独成段。
- **跨段大段引用禁止**：要拆成短句重新组织（依然保留原文术语）。

## 八、数值与日期

- 年份用 `2018 年`，季度用 `2018Q2` 或 `2018 年二季度`（沿用文档措辞）。
- 涨跌幅、市值、净值数据：仅当文档明确给出才能写，且照原文写法。
- **绝对禁止**：自己凭空给出回报率、年化超额、夏普比率等量化指标。

## 九、不允许出现的内容

- 任何形式的"建议买入/卖出""目标价""未来 X 个月会涨跌"。
- 任何外部数据（沪深 300 点位、行业指数、个股代码、宏观 CPI/PMI 等），除非文档原文出现。
- "参考其他研报""综合多方观点""市场普遍认为"等措辞。
- "我认为""我推测""我个人觉得"等主观语气（除非是直接引用经理本人的话）。
- **文档未提及的教育背景**：允许通过 MCP/外部知识补充学校、专业、年份，补充内容直接写入 Part1 教育背景段落，不得在报告末尾另加附录节。
- **文档未提及的任职履历、业绩数字**：省略不写，不得从训练数据或外部知识补充。
