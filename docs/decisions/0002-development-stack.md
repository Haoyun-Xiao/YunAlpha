# 0002 前后端初始化

2026-11-06，用户批准精简版初始化。

采用 React、TypeScript、Vite；Python3.12、FastAPI、Uvicorn。npm与uv提交锁文件，使用工作树自己的依赖目录。
独立单Worker顺序执行环境自检，任务保存在本工作树SQLite。页面轮询状态；重启时重做未完成自检，不做租约、心跳、分步骤恢复或通用调度。
本轮只有环境页，不接模型、研究报告、策略或旧站点。既有基金报告和组合回测的设计与云服务保持原样。
数据湖只检查目录是否可读取，不调用湖SDK、不写正式目录、不声称数据完整。
端口默认19100/19101，冲突需在本机配置中改为另一组；不自动分配。
