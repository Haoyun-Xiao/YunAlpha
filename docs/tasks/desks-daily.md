```sh
apps/vic_desks/.venv/bin/python apps/vic_desks/scripts/refresh_daily.py \
  --lake-config "$LAKE_CONFIG" --base-runtime "$BASE_RUNTIME" \
  --seven-version "$SEVEN_VERSION" --crowding-version "$CROWDING_VERSION"
```

`--base-runtime` 传当前已选版本所在的运行根（即含 `phase2/vic_desks/` 的目录）；`YUNALPHA_RUNTIME` 传本次输出根，未配置时取应用所在项目的 `.runtime`。使用应用已锁的 DuckDB、pandas 和 PyArrow，只读正式 TOML 中的绝对 `data.root`（交易日历及正式 Parquet），无需湖 SDK、旧项目、采集权限或网络请求。`--as-of` 只约束北京时间上界，落地日期由交易日、来源实际可见度及完整性决定。

`$YUNALPHA_RUNTIME/phase2/vic_desks/daily/latest.json` 与命令标准输出用相同 JSON。顶层 `status` 为 `ready`（候选相对传入版本变化）、`unchanged`（无需切换）或 `failed`（退出非零，不选版）；`candidates.seven.version`、`candidates.crowding.version` 总是存在。状态还含候选位置、是否新生成、分项日期/原因和验收结果。竞争构建返回非零，保留正在执行那次的状态文件。发布候选前检查源文件构建期间没有被替换，再跑代表接口；候选只能由总控选版与启停。此分支未改共享 wrapper、配置或主站，也未更改抱团代码。
