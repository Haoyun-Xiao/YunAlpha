# DS Agent 市场查数与代理 MCP

研究会话用 `market_lake_lookup` 查询指定交易日、一只股票未复权开高低收或 A 股交易日历。湖缺记录、用户指定代理或要求显式对账时，`deepseek-v4.1-flash` 助手可用 `market_proxy_lookup` 查询同一范围的外部数据。工具保留日期、单位、复权方式和来源，对账时两端值独立展示。无记录时不推断停牌或休市。

代理客户端通过当前数据湖配置定位 HTTPS MCP，按代理教程在进程内传递 token。每次查询读取湖配置同目录的 `.env.local`，可直接使用日更的新 token，无须给 Agent 单独配置一份。配置和会话记录使用脱敏来源名。若本机湖配置位置改变，沿用主工作区 `lake_config`，或在独立运行环境中指定 `YUNALPHA_LAKE_CONFIG`。

投研台和策略继续使用正式湖的输入及现有冻结结果。日更仍由湖执行增量、覆盖核对和发布，再刷新看板。外部 MCP 适合补充会话中的小查询和对账。若将来有日更之外的持续更新需求，先确认所需频率、数据口径与源覆盖，再决定是否在湖侧增加采集入口。

## 2026-11-18 本机实测

隔离的 YunAlpha 研究会话使用同一 DS 模型，测量工具耗时和从提问到最终答案的耗时。股票样本为 2026-11-17 贵州茅台 `600519.SH` 的未复权日线。

| 会话 | 工具耗时 | 端到端 | 结果 |
| --- | ---: | ---: | --- |
| 默认读湖 | 21 ms | 9.3 s | 开 1458.88、高 1461.60、低 1437.71、收 1457.70，标注 CNY、日期和正式湖 |
| 指定代理 MCP | 5.9 s | 15.2 s | 四项一致，标注日期、单位和外部代理来源 |
| 交易日历对账 | 湖 18 ms、代理 7.2 s | 18.7 s | 两端均开市，答案区分了湖的 A 股日历与代理 SSE 日历 |

单次样本用于对比可用性与答复，耗时不是稳定性或吞吐测试。验收的脱敏回执保存到 `.runtime/artifacts/agent-market-mcp/results.json`。
