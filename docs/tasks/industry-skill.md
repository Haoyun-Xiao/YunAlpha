# 产业链研究 Skill 与统一 Agent

基线 `dcb17f5`。总控工作树 `codex/industry-skill` 负责前端 Skills 页、会话成果卡、共享依赖、部署启动与验收；`codex/industry-workflow` 负责产业链源码迁入、Skill、Agent 工具与后台任务。旧项目 `/path/to/local-user/项目/产业链研究Agent` 只读，来源提交 `6ceb3ace647257a3343b21e1baac02826d3c88de`。

## 本轮范围

- 保留原有准备材料、结构规划、公司核验与冻结取数、分环节研究、独立审核、综合、导出七阶段；保留既有六维方法和断点恢复。
- 原 Skill 与详细方法迁入实际 Deep Agents 的 Skill 目录。研究工作流与统一会话使用同一份方法，不依赖原仓路径。
- Skills 页从 Agent 的实际目录读取，支持查看方法、搜索和进入会话。点“在 Agent 中使用”创建会话、填写提示；由用户补充对象后发送，不直接启动长报告。
- Agent 可创建、查询、恢复、取消产业链任务，读取研究成果。会话持久化 `industry_job` 块，与基金报告卡区分；重开会话仍能查看进度和成果。
- 用现有 Agent API/Worker 和本仓独立状态运行，不另建聊天系统。正式数据湖只读，研究成果落 YunAlpha，不自动写入正式湖。

## 接口与验收

前端经 `/agent-runtime/api/v1/skills` 读取目录；产业链任务使用 `/agent-runtime/api/v1/industry-jobs/{job_id}` 及 view、resume、cancel、下载入口。进度按 0–100 返回，与基金任务的 0–1 区分。

验证前端构建、Skill 可发现及工具注册、任务创建与状态恢复、本地报告打开。主控使用真实模型从统一 Agent 发起一个新产业链研究样本，核对新任务经过既有流程而非历史报告回放。原项目保持不变。主控验收端口 19240（前端）、19241（Agent），运行目录为该工作树 `.runtime/`；后台线若需 API 使用 19242。
