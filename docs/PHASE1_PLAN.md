## 如何并行

1. **并行核对。** A 核对 VIC 布局证据；B 核对报告和投研台来源；C 核对策略入口和真实可执行范围。总控汇总，确定模块标识、分类、入口类型、可用状态和最小接口样例，不先造通用插件系统。
2. **先提交接口，再三路开发。** 总控提交最小约定；A 使用约定样例开发 UI，B/C 实现真实目录与适配。接口变化由总控同步，避免分别猜测。
3. **分批合入。** B/C 任一路完成即可验收并合入，A 更新到集成基线接真实接口，不必等三路同时结束。各分支按小块可运行成果交付。
4. **总控联调。** 走通导航、投研台到报告、策略目录到已有能力。用户验收布局、信息组织和使用体验。下一阶段再开 Agent 迁入任务。

对话可以按领域保留，分支和工作树按任务短期使用。完成后合入 main、收回工作树，下一项从新基线创建。子 Agent 只用于明确独立的检索、局部实现或审查，遵循现行全局模型路由，不固定再套一层负责人。
